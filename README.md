# 望挽Game🎮环境一键隐藏
> 专为Folkpatch/Magisk打造的MiuiX风格游戏环境隐藏模块

## 📌 模块信息
- **模块名称**：望挽Game🎮环境一键隐藏
- **模块版本**：20260529
- **适配平台**：Magisk / Folkpatch
- **界面风格**：MiuiX 原生简约
- **开源地址**：https://github.com/WangwanPD/Wangwan

## ✨ 核心功能
1. **一键配置模块**：自动完成游戏隐藏全套基础配置
2. **一键更新Keybox**：云端拉取最新认证文件
3. **一键更新ts包名**：自动同步最新游戏隐藏包名列表
4. **赞赏作者**：远程图片弹窗赞助

## 🚀 使用说明
1. 下载模块刷入Magisk/Folkpatch
2. 重启设备
3. 打开Folkpatch → 模块 → 望挽Game
4. 点击对应按钮一键执行功能

## 🔄 远程更新
所有配置文件、功能资源均支持**云端远程更新**，无需重新刷入模块。

## 💡 注意事项
- 建议Magisk版本 ≥ 23.0
- 需开启网络用于远程资源下载
- 仅用于游戏环境隐藏，请勿用于非法用途
